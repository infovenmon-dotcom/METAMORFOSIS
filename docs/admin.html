Productos
Producto Precio (€) Antes (€) oferta Stock Agotado

• Precio: déjalo en el precio normal o cámbialo.
• Antes: para una oferta, pon aquí el precio anterior (mayor que el actual). Se mostrará tachado con el % de descuento. Vacío = sin oferta.
• Stock: vacío = no se controla; un número se irá descontando con cada venta; al llegar a 0 ese producto se vende en Amazon.
• Agotado: fuerza "Comprar en Amazon" sin tocar el stock.
