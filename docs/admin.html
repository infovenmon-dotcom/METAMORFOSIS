Producto Precio (€) Antes (€) oferta Coste (€) interno Stock Agotado

• Precio: déjalo en el precio normal o cámbialo.
• Antes: para una oferta, pon aquí el precio anterior (mayor que el actual). Se mostrará tachado con el % de descuento. Vacío = sin oferta.
• Stock: vacío = no se controla; un número se irá descontando con cada venta; al llegar a 0 ese producto se vende en Amazon.
• Agotado: fuerza "Comprar en Amazon" sin tocar el stock.

📊 Centro de cuentas

Ventas, comisiones de Stripe, IVA y neto de un periodo. Para tu control y para tu gestor (exporta a CSV).

El IVA se calcula al 21% sobre el total (los precios ya incluyen IVA). Confírmalo con tu gestor; algunos productos podrían tener otro tipo.

💰 Beneficio real

Documento interno. Calcula tu beneficio: ventas (sin IVA) − coste de lo vendido − comisiones de Stripe. El coste de cada producto se pone en la pestaña "Productos".

El "IVA soportado" es el IVA de tus compras/gastos del periodo (lo pones tú; tu gestor lo afina). "IVA a ingresar" ≈ IVA de ventas − IVA soportado. El margen no descuenta gastos generales ni impuesto de sociedades.
